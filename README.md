# 多天气系统引擎（星程气象）

Spaceflight Simulator（SFS）天气模组：**7 类天气系统**自然生成、演化、移动、合并与类型转变，真实风场 / 降雨 / 龙卷 / 下击暴流 / 沙尘暴，全程可交互。

> 当前版本 **v2.2.24**。本 mod 由 AI 辅助设计制作。

**v2.2.4 – v2.2.24 改动**

- **风暴雷达重做 + 龙卷预报并入雷达**：以玩家为中心（原玩家钉在左边缘）、发光风暴团 + 云塔 + 地面投影（尺寸 ∝ Rmax、颜色 = 强度）、龙卷画成垂到地面的红色漏斗点（脉冲）；下方直接给预报：最近龙卷的**类型 / EF 级 / 距离 / 方位 / 现实秒抵达倒计时 / 本系统剩余潜势 / 伴生现象**。
- **龙卷预警曲（可选）**：龙卷抵达前 **15 现实秒**（大型龙卷 19 秒）起播风暴拦截者风格曲目，淡入淡出、离开后自动收尾、按遭遇时长自适应提速。
- **龙卷风场影响范围修正**：尺度从 `Rmax×0.3`（超单 ≈1.1km，5km 外仍有 20 m/s）改为**漏斗核半径** + 快速截断（1km 外基本无风）；卷入判定半径从 `Rmax×0.55`（≈2km）改为核半径×4 —— 让**风场 = 判定 = 看得见的漏斗**三者对齐。
- **超巨型档**：核半径上限提升到 **~1000 m（2 km 宽）** —— 峰值风速达 EF5 的极端龙卷（需合并满级 + 顶种子）才会进入该档，对应 2013 El Reno 那种尺度；普通龙卷 138-334 m。
- **EF 等级修正**：原来读的是**母体**眼壁风（20-40 m/s，永远显示 EF0-1），现在按**龙卷自身峰值风速**计算，与风场/判定同源，种子散布改平方分布（EF4+ 稀有）。
- **下击暴流视觉提升**：下冲锥（上窄下宽）+ 云底亮柱 + 三层触地出流锋（尘体/亮前锋/外圈余波）+ 触地尘爆。
- **类型转变动画**：淡出 → **中点换型**（尺度突变与粒子重分布藏在最暗那一帧）→ 淡入，整团天气（云/雨/附属/天空穹顶）一起呼吸。
- **修掉两个确定性 bug**：① 自然生成概率门 `seed×常数 % 10000 < dt×rate` 恒不成立（seed 是常量）→ 自然龙卷/下暴/阵风锋/闪电与类型转变**从未触发过**；② 类型转变表默认值写成"单体" → MCS 会退化降级（MCS 成熟期 13 次判定，几乎必然发生）。
- **UI**：指挥中心排版修复（右上大片空白、拖动边界钳制、双击复位、行内文字重叠、列表行文字被按钮底图盖住）；HUD 性能（跳过 Layout 通道、白贴图缓存、复用缓冲）。

**v2.2.3 改动**

- **现实性审计修正**：登陆台风风速衰减真正生效（原来每帧被档位公式覆盖、从不累积的潜伏 bug；速率同时改为现实 e-folding 18h÷地形粗糙度）；沙尘暴云顶 8km→4km（对齐自身调研的"沙尘顶 1-5km"）；普通单体/多单体峰值风抬到现实阵风区间（12→18 m/s、20.8→30 m/s）；微下击暴流下沉核 55→40 m/s、地面出流 60→55 m/s（观测极值 67 m/s）；EWRC 冷却 1 天→2 天（现实 1-3 天）；龙卷/下暴/阵风锋改为**现实配额**（仅约 1/3 风暴产龙卷、一生 1-3 个，同时最多 2 个——原来成熟期几乎恒挂 4 个，比现实高两个数量级）。
- **性能**：不可见风暴整体跳过；雨层整层隐藏不再清零+上传两万顶点；**quad 的 UV 改为一次性上传**（原来每帧重传 122KB/网格）；back 网格按实际现象数量动态预留（典型省 ~30% 顶点上传）；相机集合/置顶材质不再每帧重设。
- **自然生成改按游戏时间计时**（时间加速 = 快进）：原用现实秒计时，1000× 加速下"每 30-70 现实秒一个风暴"= 13-28 游戏小时一个，与现实节奏割裂；现在间隔以**游戏时间**计（默认 1-3 游戏小时一个对流系统，设置页按游戏分钟调），时间加速倍率越高生成同步越快，与生命周期/移动/升级同一套口径。旧 json 自动一次性迁移（`cfgVersion<3`）。
- **结构**：三阶段生命周期时长并入类型参数表（原 Advance 内三条 if-else 硬编码链）；删除 16 个死字段（配置 6 + 系统 6 + 雨滴结构 4）与粒子诊断日志。

## 一、特性总览

| 天气系统 | 说明 |
|---|---|
| 🌪 台风 | 热带气旋，萨菲尔-辛普森分级，能量制生命周期，海温驱动 |
| ⛈ 超级单体 | 深厚中气旋，可产龙卷（楔形 / 多涡旋 / 卫星） |
| 🌫 飑线 | 线状 + 弓形剖面 + 阵风锋，可产龙卷 |
| ☁️ MCS | 中尺度对流系统，大云砧 + 核塔 |
| ⛅ 多单体 | 团状，新生单体更替 |
| 🌩 单体雷暴 | 普通雷暴，永不升级 |
| 🏜 沙尘暴 | 沙墙推进（Haboob），无降雨 |

**核心机制：**

- **能量制生命周期** —— `energy` 0-100 驱动发展 → 成熟 → 消散，按**现实气象尺度**标定（台风 5 天 / 单体 45 分钟游戏时间），时间加速 = 快进等待
- **海温场 + 台风冷尾流** —— 行星级海温采样（种子生成），台风暖水加油 / 冷水熄火 / 登陆断供；强风搅动挖冷水自我削弱（负反馈闭环）
- **眼壁置换 EWRC** —— 成熟强台风周期"先弱后强、眼先糊后清、眼径外扩"
- **龙卷 8 类型** —— 标准 / 楔形 / 绳状（rope-out 消散）/ 水龙卷 / 陆龙卷 / 多涡旋 / 卫星 / gustnado，环境自动派生
- **消散衍生产物** —— 台风残余低压（逗点化 + 消散延长）、云底侵蚀（从下往上散）、沙尘泥雨（跨系统）
- **类型转变链** —— 单体 → 多单体 → 超级单体 → MCS、飑线 → MCS（组织化升级）
- **Fujiwhara 效应** —— 双台风合并时绕共同中心互旋逼近
- **进存档预生成** —— 进存档 / 换星球时自动给当前行星播种风暴（世界一进去就是活的，数量与台风概率可调）
- **地图标记** —— M 地图视图显示风暴**矩形轮廓**（边长 2Rmax = 核心直径，台风另有 5Rmax 外围虚线框）+ 点 + 文字标签（颜色 = 强度色），不用切回近地就能看到风暴分布
- **天气音效** —— 程序化合成风声（布朗噪声 + 呼吸起伏）/ 雷声（白噪声轰 + 低频 + 回响），零音频文件；按风暴距离 2.5Rmax 平方衰减，音量设置页可调
- **SFS 设置页** —— 官方 Settings → Mods Settings → 星程气象（3 页签可调）
- **2D 横截面渲染** —— 全部形态按行星剖面语言表达（眼 = 碗形凹陷、墙云 = 云底悬挂、砧 = 顶部平展）

## 二、安装

### 步骤

1. 下载 Release 里的 `MultiWeatherEngine.dll`
2. 放入 SFS 模组目录：
   ```
   <Steam>\steamapps\common\Spaceflight Simulator\Spaceflight Simulator Game\Mods\MultiWeatherEngine\
   ```
3. 启动游戏，进入一个世界（存档），按 **F6** 打开气象菜单

### 可选：龙卷预警曲（自备音频）

预警曲**不随仓库分发**（曲目版权归原作者）。想用的话，把自己的曲目转成 **16bit PCM WAV** 放进 mod 目录：

```
Mods/MultiWeatherEngine/storm_chase.wav       # 常规龙卷（提前 15 现实秒）
Mods/MultiWeatherEngine/storm_chase_big.wav   # 大尺度龙卷（提前 19 现实秒）
```

文件名/提前量/触发阈值都可在 `typhoon_config.json` 里改（详见"设置页"章节）。缺文件时自动回退到另一首；两首都缺就静音，不影响其他功能。

> 转换示例（任意工具均可，关键是 **16bit PCM**）：
> `ffmpeg -i 原文件 -vn -ac 2 -ar 22050 -acodec pcm_s16le storm_chase.wav`

## 三、操作指南

| 按键 | 功能 |
|---|---|
| **F6** | 气象指挥中心菜单（召唤 7 类天气系统 + 附属现象） |
| **F7** | 解散选中的系统 |
| **F8** | 选中系统强度 +1（0-6 级，超出类型上限会标 ⚠超限） |
| **F9** | 底部"活跃天气系统"面板展开 / 收起 |
| **Shift+F7** | 隐藏 HUD |

### 基本流程

1. **F6** 打开菜单 → 点击类型按钮召唤（召唤点自动落在相机视距内）
2. 底部面板（F9）列出所有活跃系统：点击行 = 选中（左上详情面板显示该系统的完整数据）
3. 左上详情面板：阶段 / 能量 / 等级 / 峰值风 / 云底云顶 / 移速 / 地形 / 海温（台风）/ 本地风 / 风圈 / 附属现象
4. 菜单内"加龙卷 / 加下暴 / 加阵风锋 / 加闪电"为选中的系统附加现象
5. 选中系统按 **F8** 手动强化（可越过自然上限，god mode）

## 四、能量制与生命周期（现实尺度）

每个系统分三阶段，各有一张按类型的速率表（游戏时间，时间加速 = 快进）：

| 系统 | 发展 | 成熟 | 消散 |
|---|---|---|---|
| 台风 | 2.5 天 | 5 天 | 12 小时（残余低压 ~18h） |
| 单体 | 20 分钟 | 45 分钟 | 20 分钟 |
| 多单体 | 1.5 小时 | 8 小时 | 3 小时 |
| 超级单体 | 1.5 小时 | 8 小时 | 2 小时 |
| 飑线 | 3 小时 | 18 小时 | 6 小时 |
| MCS | 3 小时 | 18 小时 | 6 小时 |
| 沙尘暴 | 4 小时 | 24 小时 | 8 小时 |

- **地形因子**：海上 1.0 / 绿地 0.55 / 岩石 0.45 / 冰原 0.18 / 沙漠 0.28（沙尘暴在沙漠 0.9，靠风驱动反而持久）
- **海温**（台风）：≥26.5°C 增强、<24°C 发育失败（冷水冷死台风）；海上净耗散 ÷ sstF²
- **登陆衰减**：水汽切断 + 摩擦 → 消散加速（台风登陆 12h → 岩石 5.4h / 沙漠 2.7h）
- **大气分级**：巨行星寿命 ×30（大红斑完整 240 天）、金星 ×3；巨行星台风不依赖海温（大气环流机制）
- **消散可见性**：无论多大时间倍率，消散过程都以帧驱动保证肉眼可见（能量归零 + 5 秒渐隐）

## 五、设置页（Settings → Mods Settings → 星程气象）

| 页签 | 内容 |
|---|---|
| 通用 | HUD 显示 / **地图标记风暴** / **天气音效（开关 + 音量 0-1）** / 风暴视觉效果 / 闪电 / 相机抖动 / 抖动强度 / 召唤偏移 / **等级与消散 5 开关（含现象现实配额）/ 自然生成（开关 + 间隔(游戏分钟) + 距离）/ 预生成（开关+数量+台风概率）/ 影响宇航员 / 快捷键说明** |
| 粒子 | 云顶薄云粒子数 / 主体云粒子数 / 雨滴数 / 云·雨不透明度 / 雨尺度 |
| 风场 | 阵风幅度 / 外流比例 / 天空覆盖度 |

数值实时写回 `typhoon_config.json`（模组目录下，可手动编辑）。

> 关闭"等级上限" = chaos 模式：所有系统可自然升到 6 级。

## 六、科学性设计（数值均有气象依据）

- 萨菲尔-辛普森风速表（台风分级）、蒲福风级、26.5°C 海温生成阈值
- 冷尾流：风应力二次方依赖（`τ∝V²`，62 m/s 稳态挖深 ~3.8°C）、混合层 3-6°C 可挖深度、恢复 ~1.2 天
- EWRC 周期 1-3 天（代码 1 天冷却）、眼壁置换先降后升
- 等级上限按类型：台风 6（萨菲尔全表）、沙尘暴 4（国标）、超单/飑线/MCS 4、多单体 2、**普通单体 1（永不升级）**
- 消散产物：台风变性残余低压、冷池出流、沙尘沉降（泥雨）——均为现实消散链的"尾巴"

**已知简化**（SFS 2D 限制）：行星无纬度/三维环流概念，风切变/湿度场省略；所有形态按**横截面**表达。

## 七、已知问题

- SFS 默认字体无中文字形时 HUD 用系统雅黑渲染（Win 自带）；若字体加载失败回退默认（方块），请反馈
- 中文字体 emoji 不支持，界面使用纯文本/几何符号
- 极端时间倍率（千万级）下长寿命系统（台风/大红斑）等待仍是现实可感知的——时间加速是唯一快进手段
